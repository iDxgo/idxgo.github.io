Descripción: 
Este proyecto analiza la trayectoria térmica de México entre 1985 hasta 2024,
comparándola con la crisis climática global. A través de visualizaciones interactivas, 
se examina la transición de un aumento gradual en el promedio nacional hacia una emergencia
por extremos térmicos.

Datasets utilizados:
- Datos de México: https://datamx.io/es/dataset/temperaturas-mensuales-en-mexico-1985-2025. (Fecha de consulta: 25/04/2026)
- Datos Globales: https://www.kaggle.com/datasets/lucalullo/global-mean-temperature-by-country-1950-2024. (Fecha de consulta: 25/04/2026)
